# Two Sum CLI Solver

Java CLI application to solve the Two Sum problem using HashMap (O(n)) approach.

## Features
- O(n) HashMap solution
- Handles duplicate values
- CLI input using Scanner

## Sample Input
2 7 11 15
9

## Output
Indices: [0, 1]

## Complexity
Time: O(n)  
Space: O(n)

## How to Run
javac Main.java  
java Main
